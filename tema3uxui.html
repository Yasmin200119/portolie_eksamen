Temaet

I tema 2 arbejdede jeg med grundlæggende webudvikling med fokus på HTML og CSS. Temaet handlede om at opbygge websites fra bunden og få en forståelse for, hvordan indhold struktureres korrekt. Der blev arbejdet med wireframes og layoutdiagrammer som en del af designprocessen for at skabe overblik over sidens opbygning, inden kodningen begyndte.

Process

I arbejdsprocessen planlagde jeg først websiteets struktur ved hjælp af wireframes og layoutdiagrammer. Herefter opbyggede jeg siden med HTML og brugte CSS til at skabe layout og visuel struktur. Jeg arbejdede især med CSS Grid til at placere indholdet på en overskuelig og konsekvent måde. Undervejs justerede jeg layoutet løbende og erfarede, hvordan ændringer i CSS hurtigt kan påvirke hele siden, samt hvordan HTML og CSS hænger tæt sammen.

Læring

Gennem temaet har jeg opnået større sikkerhed i arbejdet med grundlæggende HTML og CSS. Jeg har lært vigtigheden af planlægning før kodning og fået en bedre forståelse for, hvordan struktur og layout er afgørende for et velfungerende website.

    Jeg har lært at:

  • opbygge websites med grundlæggende HTML og CSS
  • bruge wireframes og layoutdiagrammer til planlægning
  • arbejde med CSS Grid til layout
  • skabe struktur og overblik i indhold
  • forbedre layoutet løbende under arbejdet
