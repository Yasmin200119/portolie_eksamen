04 Grundlæggende JavaScript

"When it matters most, things must simply work."

Temaet

I tema 4 arbejdede jeg med grundlæggende JavaScript og brugergrænsefladeudvikling med fokus på at skabe interaktion på websites. Temaet handlede om at bruge JavaScript som et supplement til HTML og CSS for at gøre websites mere dynamiske.

Proces

I processen arbejdede jeg med JavaScript til at håndtere brugerinput og skabe interaktion på siden. Jeg arbejdede blandt andet med webformularer, hvor JavaScript blev brugt til at reagere på brugerens input og styre, hvad der sker, når en formular udfyldes.

Derudover arbejdede jeg med animationer og pop-ups, som blev anvendt til at vise information, skabe overblik og gøre brugeroplevelsen mere engagerende.

Gennem øvelser og projekter, herunder arbejdet med emergency site, lærte jeg, hvordan JavaScript kan styre, hvornår og hvordan indhold vises, og hvordan funktionalitet kan understøtte det visuelle design.

Læring

Forløbet har givet mig en større forståelse for, hvordan funktionalitet og interaktion spiller en central rolle i brugeroplevelsen. Jeg er blevet mere tryg ved at anvende JavaScript som et værktøj til at skabe funktionelle og brugervenlige løsninger.

Jeg har lært at:

  • arbejde med webformularer og brugerinput
  • lave animationer, der understøtter indhold
  • bruge pop-ups til at formidle information
  • skabe struktur og overblik i indhold

Reflektion

Tema 4 har givet mig en bedre forståelse for, hvordan JavaScript kan bruges til at forbedre brugeroplevelsen gennem interaktion og feedback. Jeg har erfaret, at funktionalitet ikke kun handler om teknik, men også om at skabe intuitive og meningsfulde oplevelser for brugeren.

Arbejdet med JavaScript har desuden gjort mig mere bevidst om vigtigheden af struktur i koden og tydelig sammenhæng mellem design og funktion.
